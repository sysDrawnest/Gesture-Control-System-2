# New Features V4

## 1. Presentation Controller (Most Practical)

| Gesture | Action |
|---------|--------|
| 👆 Point | Next slide |
| ✌️ Peace | Previous slide |
| ✋ Open Palm | Start presentation |
| ✊ Fist | End presentation |

## 2. Media Player Control

| Gesture | Action |
|---------|--------|
| 👍 Thumb up | Play/Pause |
| 👎 Thumb down | Stop |
| 👉 Point Right | Next track |
| 👈 Point Left | Previous track |
| 🤏 Pinch | Volume up |
| ✋ Open palm | Volume down |

## 3. Smart Home Control

| Gesture | Action |
|---------|--------|
| 👆 Point up | Lights ON |
| 👇 Point down | Lights OFF |
| ✌️ Peace | Fan ON |
| ✊ Fist | Fan OFF |
| 🖐️ Wave | Open curtains |
