🏗️ System Architecture & Workflow

┌─────────────────────────────────────────────────────────────────────────────┐
│                      GESTURE CONTROL SYSTEM FLOW                            │
├─────────────────────────────────────────────────────────────────────────────┤
│  WEBCAM ──▶ MediaPipe Hand Tracking ──▶ Gesture Classifier ──▶ PyAutoGUI   │
│     │              │                         │                   │          │
│     ▼              ▼                         ▼                   ▼          │
│  Frame    21 Landmarks (x,y,z)      Pinch/Swipe/Fist         Cursor/Click   │
│  Capture                            Confidence >85%          Scroll/Zoom    │
│                                                                             │
│  ◀────────────── WebSocket (Socket.IO) ────────────────▶ Flask Server      │
│   Dashboard Updates / Real-time Logs / Analytics / Device Management       │
└─────────────────────────────────────────────────────────────────────────────┘
Step 1: User hand → webcam capture → MediaPipe inference
Step 2: Gesture detection engine classifies (pinch, fist, peace, etc.)
Step 3: Action mapped via PyAutoGUI + Socket.IO broadcast
Step 4: Dashboard updates in real-time with logs & analytics

Security Highlights

  • JWT tokens (24h expiry) + bcrypt hashing (12 rounds)
  • Parameterized queries (SQL injection protection)
  • CORS restricted & XSS escaping
  • Rate limiting: 60 requests/minute
  • Session management + token blacklisting
Database schema: Users, Devices, Gesture_logs (SQLite/MongoDB dual support).
